RULES
Height 56 primary, 52 secondary, 48 in-card. Never below 44. Radius is always 24 — no pills.
One primary per viewport. If a screen needs two equal actions, both become secondary and the copy carries the weight.
Disabled states say why. The label changes to the blocking condition («یک گزینه را انتخاب کن»), so the button is its own error message. Never a greyed «ادامه».
Loading replaces the label, keeps the width. No layout shift, no spinner-only button.
Dark primary takes ink, not white — #0F120F on #77B98A = 8.2:1; white would be 2.1:1.
Press feedback is a 1.5% scale and one step darker, 120ms. No opacity fade — it dims the label too.

Optional, 16:9, never carries text. Absent → card starts at the topic chip with no reserved space.

Topic resolves to one of three accent families. Duration and difficulty on one row, separated by a drawn dot.

Title, max 3 lines
Content constraint: ≤ 60 Persian characters. Clamps at 3 lines with ZWNJ-safe truncation.
4
Learning promise, 1 line
≤ 80 characters, starts with a verb the reader will be able to do. Required to publish.
5
CTA + save + download
CTA label reflects progress: شروع دانه / ادامه / مرور. Both icon buttons are 46×46 with labels.
6
Recommendation reason
One short clause from a fixed set of reason codes. If ranking cannot explain the pick, the row is omitted — never invented.
VARIANTS
hero — illustration, promise, reason, full CTA row. Home only, one per screen.
rail — 230pt wide, chip + title + metadata, no illustration, whole card is the target.
continue — progress ring replaces the illustration, CTA collapses to a 44 play button.
list — 26pt status circle, title, one metadata line. Used in topic detail, Garden, search.
review — interval badge («۷ر») instead of a chip, no CTA; the row is the target.
Never place metadata over the illustration, and never let the illustration be the only way to tell two cards apart.

RULES
Three signals per state, always: indicator shape, border treatment, and a text badge. Colour is the fourth, never the first.
Selection is reversible until submit. No auto-advance on tap — that steals the decision from slow readers.
Missed uses a dashed border so partial credit is three visually distinct outcomes, not a shade of the other two.
Wrong options are not hidden after submit, only de-emphasised to 50% — the reader needs to see what they rejected.
Min height 56, grows with text. At 200% type, options stack full-width and the indicator stays 22 at the start edge, top-aligned.
Screen reader: role=radio, state announced as «انتخاب‌شده، پاسخ درست» — never «green».

Three rules that cut the matrix down
A component that can be empty must have its own empty copy — no shared "چیزی نیست". A component that can fail must offer a second action. A component that can be stale must say when it was last true.
Refreshing ≠ loading
Loading shows a skeleton because there is nothing to show. Refreshing keeps the old content fully legible and marks it stale — pulling to refresh must never blank the screen you were reading.
Focused is web-first
The 2px offset ring exists for keyboard and web. On native it is drawn only when an external keyboard or switch control is attached, so it never appears mid-tap.
