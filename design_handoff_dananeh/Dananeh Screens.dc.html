دانانه · Dananeh Round 2 — screens

Core screens, RTL first

Drawn at 390pt, Persian first, using the tokens from Foundations. Dates are Jalali only. Seed imagery appears as labelled illustration slots — the system assumes one commissioned editorial illustration per topic, never stock photography. Topic colour resolves to one of three accent families: sciences → primary, humanities → plum, practical → sun.

Icon note: the repo ships only two tab assets — assets/images/tabIcons/home.png and explore.png, solid black bitmap glyphs with no Garden or Profile equivalent and no stroke weight to match. The four tab icons here are new brand artwork on the 24×24 / 1.75-stroke grid that replaces them, built from the same concentric-ring geometry as the mark; they ship as vectors, not PNG sets.

Seed player — content blocks

One seed, drawn block by block: «چرا آسمان شب کاملاً تاریک است؟». Header chrome is identical on every block — close, truncated title, segmented progress with a text equivalent («۴ از ۱۱»), save and more. The CTA is always in the same place, so the only thing that changes between blocks is the content itself. Progress fills from the right.

These are not flipped screenshots.
